# BIE

Aplicación nueva y limpia para controlar BIE.

## Incluye

- Importar Excel desde el checklist BIE manteniendo registros repetidos.
- Filtrar por cliente, edificio, número SYCo y nº serie.
- Ordenar por cliente, edificio o número SYCo.
- Editar registros y añadir nuevos.
- Campo cliente antes de edificio.
- Número SYCo después de edificio.
- Fabricante/marca, operaciones realizadas, caducidad 20 años, tipo de revisión y estado del equipo.
- Modelo con desplegable: 25, 45 y 25T45.
- Fechas con desplegable de años.
- Señal de 2017 a 2026.
- Defectos múltiples de BIE.
- Comprobaciones A-W y R1-R7 del checklist BIE.
- Al guardar un dato nuevo vuelve al formulario para seguir tomando datos.
- Dos fotos por registro, con opción de eliminar/cambiar.
- Eliminar todos los registros existentes antes de cargar otro cliente.
- Descargar Excel con datos, defectos y fotos.

Los datos y fotos se guardan en el navegador/móvil mediante IndexedDB.
